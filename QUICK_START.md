## 🆘 TROUBLESHOOTING

**Portfolio looks broken?**
- Clear browser cache: Ctrl + Shift + Delete
- Refresh: Ctrl + Shift + R
- Try different browser

**Contact form not working?**
- Use Formspree.io (better option)
- See OPTIMIZATION.md for setup

**Looks bad on mobile?**
- Force refresh on phone
- Test in different mobile browsers
- Check CSS media queries

**Can't find files?**
- Go to: C:\Portfolio
- In Windows: File Explorer → Type path
- Folder should have all files listed above
